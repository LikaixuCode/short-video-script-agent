# 方案设计

Claude Agent SDK 0.2.175 负责调用 GLM、循环选择工具、处理 MCP 往返和轮数上限。配置 `tools=[]`、只允许进程内注册的业务 MCP 工具、`strict_mcp_config=True` 和 `setting_sources=[]`，避免接入本机其他工具配置。模型选择查询和脚本版本；本地工具独立核验输出。

工具为 `search_materials(query, reason)`、`estimate_duration(script_json, reason)`、`check_rules(script_json, reason)` 和 `finalize_script(script_json, reason)`。第四个工具用于交付最终脚本，并非真实发布。每次调用的 `reason` 是模型提供的简短公开依据，不要求或记录内部思维。系统根据调用顺序记录下一动作，并保留 SDK 的工具请求 ID 和返回 ID。

检索先根据输入主题与预设同义词限制可用素材，再根据当前查询与素材索引匹配；模型可改写索引词，但不可把无关题目换成任意素材。源码内素材和规则加载后属于本次运行快照；更改文件会影响下一次运行。

每镜事实使用 `source_id + fact_id`，旁白和字幕必须等于该事实原文，画面也必须等于其资料中预设的画面说明。标题限制为素材标题或规则中允许的通用标题。该白名单能阻止本样例中的无依据效果数据，但表达空间受限，不是对任意自然语言断言的语义事实核验。

时长工具计算旁白文本的非空白、非标点字符数，以每秒 4 个字符估计最低口播时长，并检查填写的每镜时长是否不低于下限。总时长用十进制计算后与目标比较，避免舍入将超时误报为通过。这不是实测配音时长。

脚本规范化后生成 SHA-256 指纹。通过的时长与规则结果分别绑定该指纹，提交时必须找到同一指纹的两项通过结果。任何字段变化都需要重查；不接受模型自己声称“已经检查”。执行次数上限在业务工具侧拦截，SDK 另设轮次上限。已执行步骤记录于输出，模型错误不会当作成功。
