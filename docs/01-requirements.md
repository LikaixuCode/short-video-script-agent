# 需求与验收

题号 4，目标用户为短视频创作者。输入主题、受众、平台、目标时长和风格；基于合成产品素材与品牌规则，生成标题、分镜、旁白或字幕、每镜及总时长、来源 ID、风险和任务状态。

必须覆盖：正常生成、缺少关键信息、无素材、工具失败、超时长后修改并复查或明确失败。检索无结果时模型可以换词或停止；时长与规则失败后可以调整脚本并重新检查。脚本不能编造素材中不存在的事实。

成功标准：完成状态必须由实际通过素材与主题覆盖、品牌规则、目标时长范围和每镜朗读下限的检查，且提交同一版本脚本共同决定。默认总时长为目标的 80%–100%，允许输入调整容差；这是本项目的质量规则，题目未规定固定误差比例。失败时返回未完成，Trace 保留已发生的步骤。只输出计划脚本，不制作或发布视频。
