# AI 使用说明

本项目按用户要求由 Agent Teams 协作实现：一个开发 Agent 负责题目四项目实现、示例和测试；主 Agent 统筹交付与核验，审阅 Agent 独立检查边界。Codex 参与代码、测试和文档编写；运行时使用 GLM 生成和调整脚本，Claude Agent SDK 负责模型循环和自定义工具调用。

独立审阅发现检索改写在原主题不匹配时无法成功，以及小数时长舍入可能掩盖超限。开发 Agent 分离主题同义词和索引词，并改用十进制求和，添加回归测试。实际测试结果见 [03-evaluation.md](03-evaluation.md)。

用户提供题目需求和协作方式；未掌握用户是否亲自修改代码的信息，因此不代写其个人修改经历。提交前可由用户补充本人实际参与和理解，避免虚构。
