# 复盘

难点是让模型能自由调整镜头，同时避免将模型生成的产品描述当成事实。此实现选择较严格的素材原文白名单，让输出可逐镜核查；代价是无法充分改写文案风格，且只支持合成素材中预先配置的主题别名。

实际检查还发现：仅记录素材 ID 不足以证明文案受素材支持；仅展示两位小数可能掩盖时间超限。因而加入逐句核对、脚本指纹绑定和十进制时长计算。

第二轮审阅发现，仅验证原文与来源相同不能保证脚本覆盖了用户主题；也不能把未完成的后续脚本当成之前已提交的脚本。修复后会检查明确的主题事实类别，保留资料缺口和旧稿历史，并将工具执行顺序与同一模型消息中的并列请求区分开。有限词表和原文格式仍需人工维护，不保证覆盖任意自然语言。

下一步可引入可审计的语义检索、可验证的事实主张拆分、品牌规则扩充以及真实口播时长测量。这些均未在当前项目中实现。

用时以本地开发与验证的记录范围为准，见评估文档；不将预期耗时冒称实际用时。
